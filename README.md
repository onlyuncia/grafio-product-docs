# Grafio: кейс бизнес- и системного анализа

Проект финансовой аналитики продавца Wildberries: от ручной недельной сводки в Excel до целевого процесса с проверкой данных, расчётами, детализацией, контролем расхождений и управляемыми версиями методики. Проектный контекст — апрель 2026 года.

**Начните с [краткого кейса](CASE-STUDY.md).** Он объясняет задачу, мою роль, принятые решения и границы результата. [Галерея](screenshots/README.md) показывает основные экраны, а [кликабельный прототип](prototype/README.md) позволяет пройти сценарии на демонстрационных данных.

## Что означает статус проекта

Требования, модели и API описывают **целевой финансовый контур**. Прототип работает с синтетическими данными и не является реализацией расчётного backend. Проверка полей нового финансового API WB на обезличенной фактической неделе остаётся открытой; измеренный эффект внедрения не заявляется. [Журнал проверки прототипа](docs/validation/prototype-uat.md) относится к зафиксированному срезу интерфейса.

В [редакторском решении](docs/editorial-decisions.md) указано, какие исходные документы сохранены, почему они сгруппированы именно так и какие рабочие материалы не вошли в этот репозиторий.
