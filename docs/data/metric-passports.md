# Паспорта показателей недельного отчёта

Статус: паспорта и контрольные решения утверждены автором. Точные поля WB сопоставляются в контракте данных.

## Как читать документ

Паспорт отвечает на четыре вопроса: что означает показатель, как он рассчитывается, когда он недоступен и как проверить результат. Общие правила применяются ко всем паспортам; справочник расходных категорий описывает классификацию и не создаёт отдельную формулу для каждой статьи.

На первом чтении сосредоточьтесь на выручке, возвратах, выкупах, расходах, себестоимости, марже, маржинальности и расхождении сверки. Остальные разделы уточняют настройки и исключения.

## Общие правила

| Правило | Принятое определение |
|---|---|
| Контекст | Выбранный кабинет WB, связанное юридическое лицо, завершённая неделя ПН–ВС. Одно юридическое лицо может иметь несколько кабинетов |
| Основной период | Срез по начислению: операция относится к неделе финансового отчёта, в которой отражена |
| Денежная единица | Рубли; расчёт сохраняет копейки и не округляет строки до суммирования |
| Отображение | Пользователь настраивает количество знаков после запятой; расчёт и проверки всегда ведутся с полной точностью |
| Детализация | Отчёт → категория → товар при наличии связи → исходная операция |
| Отсутствие | Отсутствующее значение не равно нулю; зависимый показатель получает «Не рассчитывается» с причиной |
| Расходы | Положительное значение уменьшает маржу; отрицательное увеличивает её, например компенсация или сторно расхода |
| Полнота | Определяется относительно включённых в отчёт источников и опций |
| Версия | Значение воспроизводится только вместе с версией правил, входных данных и настроек отчёта |

## Контрольный набор данных

Учебный пример, не клиентские данные:

| Показатель / статья | Значение, ₽ |
|---|---:|
| Выручка | 100 000 |
| Возвраты | 10 000 |
| Выкупы | 90 000 |
| Комиссия | 13 500 |
| Прямая логистика | 9 000 |
| Обратная логистика | 1 800 |
| Эквайринг | 1 800 |
| Хранение | 900 |
| Реклама | 4 500 |
| Пользовательские расходы | 3 000 |
| Налог | 5 400 |
| Итого расходов | 39 900 |
| Себестоимость | 27 000 |
| Маржа | 23 100 |

Проверка структуры: 23 100 + 27 000 + 39 900 = 90 000 ₽. Доля расходов — 44,3%, себестоимости — 30,0%, маржинальность — 25,7%, ДРР от выкупов — 5,0%.

## Денежная база

### MTR-01. Выручка, ₽

| Поле | Определение |
|---|---|
| Назначение | Показать выручку до вычитания возвратов, отражённых за неделю |
| Формула | Сумма нормализованного денежного эффекта операций, формирующих выручку, и их корректировок за отчётную неделю |
| Источник | Финансовые операции WB; конкретные типы определяет версия правила классификации |
| Знак | Продажа увеличивает показатель; сторно или уменьшающая корректировка снижает его |
| Исключения | Не включает возвраты, расходы и банковское поступление |
| Контрольный пример | 100 000 ₽ |

### MTR-02. Возвраты, ₽

| Поле | Определение |
|---|---|
| Назначение | Показать сумму возвратов, уменьшающих выкупы текущей недели |
| Формула | Сумма нормализованного эффекта операций возврата и их корректировок за отчётную неделю |
| Источник | Финансовые операции WB |
| Знак | Возврат хранится как положительная сумма для вычитания; сторно возврата уменьшает показатель |
| Исключения | Дата исходного заказа не переносит возврат в прошлую неделю |
| Контрольный пример | 10 000 ₽ |

### MTR-03. Выкупы, ₽

| Поле | Определение |
|---|---|
| Назначение | Денежная база структуры расходов за неделю по начислению |
| Формула | MTR-01 Выручка − MTR-02 Возвраты |
| Источник | Производный показатель из финансовых операций WB |
| Знак | Может быть положительным, нулевым или отрицательным |
| Исключения | При значении ≤ 0 суммы видны, доли в выкупах не рассчитываются |
| Контрольный пример | 100 000 − 10 000 = 90 000 ₽ |

## Расходы и маржа

### MTR-04. Сумма статьи расходов, ₽

| Поле | Определение |
|---|---|
| Назначение | Показать влияние одной категории на маржу недели |
| Формула | Сумма нормализованного денежного эффекта операций, отнесённых к категории |
| Источники | WB; при включении — реклама, налог и пользовательские расходы |
| Знак | Положительный расход уменьшает результат; компенсация или сторно расхода дают отрицательный эффект |
| Детализация | Категория → товар при наличии → операция; записи без товара сохраняются отдельно |
| Исключения | Родительская группа и дочерние статьи не суммируются повторно |
| Контрольный пример | Комиссия 13 500 ₽; её компенсация 1 000 ₽ отдельной строкой −1 000 ₽ |

### MTR-05. Доля статьи в выкупах, %

| Поле | Определение |
|---|---|
| Назначение | Сопоставить статью с денежным результатом недели и историей |
| Формула | MTR-04 / MTR-03 × 100% |
| Условия | Выкупы > 0; данные статьи и выкупов полные |
| Знак | Отрицательная компенсация даёт отрицательную долю |
| Исключения | При выкупах = 0: «Не рассчитывается — выкупы равны нулю»; при выкупах < 0: «Не рассчитывается — возвраты превышают выручку» |
| Контрольный пример | Комиссия: 13 500 / 90 000 × 100% = 15,0% |

### MTR-06. Итого расходов, ₽

| Поле | Определение |
|---|---|
| Назначение | Получить полный расходный эффект состава, выбранного для отчёта |
| Формула | Сумма конечных статей MTR-04, включая включённые рекламу, налог и пользовательские расходы |
| Знак | Компенсации и сторно уменьшают итог; итог может быть отрицательным |
| Неизвестные операции | При известном денежном знаке включаются отдельной статьёй «Нераспределённые» и переводят отчёт в «Требует проверки» |
| Неполнота | Если включённый обязательный источник неполон, итог не рассчитывается; доступные статьи показываются отдельно |
| Контрольный пример | 39 900 ₽ |

### MTR-07. Себестоимость выкупленных товаров, ₽

| Поле | Определение |
|---|---|
| Назначение | Показать стоимость товаров, соответствующую выручке и возвратам недели |
| Формула | Себестоимость проданных единиц − сторнируемая себестоимость возвращённых единиц |
| Источник | Версионный реестр себестоимости по товару; количество — финансовые операции WB |
| Знак | Продажа увеличивает себестоимость недели; возврат уменьшает её; итог может быть отрицательным |
| Историческое правило | Продажа использует стоимость, действовавшую для исходной продажи; связанный возврат сторнирует ту же стоимость |
| Неполнота | Отсутствующая себестоимость товара не считается нулём; итог и зависимые показатели не рассчитываются, а проблемные товары перечисляются |
| Контрольный пример | 27 000 ₽ |

### MTR-08. Маржа, ₽

| Поле | Определение |
|---|---|
| Назначение | Показать остаток выкупов после себестоимости и выбранного состава расходов |
| Формула | MTR-03 − MTR-07 − MTR-06 |
| Терминология | Денежный показатель называется «Маржа»; относительный показатель — «Маржинальность» |
| Состав | В отчёте явно указано включение налога, рекламы и пользовательских расходов |
| Неполнота | Не рассчитывается, если неполон любой включённый компонент |
| Контрольный пример | 90 000 − 27 000 − 39 900 = 23 100 ₽ |

### MTR-09. Маржинальность, %

| Поле | Определение |
|---|---|
| Назначение | Показать долю маржи в выкупах |
| Формула | MTR-08 / MTR-03 × 100% |
| Условия | Выкупы > 0; MTR-08 рассчитан |
| Знак | Может быть отрицательной при убытке |
| Исключения | При выкупах ≤ 0 не рассчитывается по тем же правилам, что доли расходов |
| Контрольный пример | 23 100 / 90 000 × 100% = 25,7% |

### MTR-10. ДРР от выкупов, %

| Поле | Определение |
|---|---|
| Назначение | Показать долю подтверждённых рекламных расходов в выкупах |
| Формула | Рекламные расходы / MTR-03 × 100% |
| Источник | Согласованный рекламный источник с подтверждённой полнотой периода |
| Условия | Источник включён и полон; выкупы > 0 |
| Исключения | Не подменяет ДРР от заказов или рекламных заказов; отсутствие источника не отображается как 0% |
| Контрольный пример | 4 500 / 90 000 × 100% = 5,0% |

## Контрольные показатели

### CTRL-01. Расхождение сверки источника, ₽

| Поле | Определение |
|---|---|
| Назначение | Сравнить сумму детальных операций с контрольной суммой источника |
| Формула | Расчётная сумма деталей − контрольная сумма за тот же отчёт, статью и период |
| Условие успеха | Расхождение в полной расчётной точности равно 0 |
| Результат | «Пройдена» либо «Требует проверки»; превышение не назначает причину автоматически |
| Исключения | Применяется только к сопоставимым суммам одной валюты и области данных |
| Контрольный пример | 10 800,00 − 10 800,00 = 0 ₽ → пройдена; 10 800,00 − 10 800,01 = −0,01 ₽ → требует проверки |

### CTRL-02. Расхождение структуры, ₽

| Поле | Определение |
|---|---|
| Назначение | Проверить согласованность карточек, таблицы и диаграммы структуры |
| Формула | MTR-03 − MTR-08 − MTR-07 − MTR-06 |
| Условие успеха | После расчёта всех компонентов значение равно 0,00 ₽ |
| Ограничение | Если MTR-08 получен из тех же компонентов, проверка является арифметическим контролем сборки и не доказывает полноту источника |
| Визуальное правило | Диаграмма не нормализуется автоматически до 100% |
| Контрольный пример | 90 000 − 23 100 − 27 000 − 39 900 = 0 ₽ |

### CTRL-03. Полнота данных

| Поле | Определение |
|---|---|
| Назначение | Определить, какие показатели допустимо рассчитывать |
| Тип | Составной статус по каждому источнику и показателю, не процент |
| Значения источника | Полные данные / неполные данные / не определена до завершения загрузки |
| Значения показателя | Рассчитан / не рассчитывается с указанием недостающего источника или параметра |
| Правило | Полнота оценивается относительно включённых опций: выключенная реклама не делает отчёт неполным; включённая, но незагруженная — делает зависимые показатели нерассчитываемыми |
| Контрольный пример | Финансовые данные полны, реклама включена и отсутствует: выкупы рассчитаны, ДРР и итог с рекламой не рассчитываются |

## Справочник категорий расходов

Один паспорт MTR-04 применяется к разным категориям; одинаковые формулы не дублируются.

| Группа | Категории первой версии | Особенность |
|---|---|---|
| Основные расходы WB | комиссия, прямая логистика, обратная логистика, эквайринг и другие подтверждённые расходы | Классификация зависит от версии правил WB |
| Платные услуги WB | операции на приёмке; размещение товара на складах WB | Выделяются отдельно для анализа тарифов и операций |
| Штрафы и компенсации | штраф; компенсация брака; компенсация ущерба | Штраф — положительный расход; компенсации — отдельные отрицательные статьи |
| Другие услуги WB | утилизация и иные подтверждённые услуги | Утилизация показывается отдельной статьёй и не объединяется с приёмкой или размещением |
| Корректировки | сторно и возвраты расходов | Отрицательный расход при увеличении маржи |
| Реклама | подтверждённые рекламные расходы | Опциональный источник; нужен для MTR-10 |
| Налог | сумма по опубликованному правилу юридического лица | Опционально; база выкупов не объявляется налоговой базой автоматически |
| Пользовательские расходы | категории, введённые пользователем | Для каждой записи выбирается неделя оплаты либо распределение по периоду |
| Нераспределённые | известная сумма операции с неизвестной категорией | Видна отдельно; отчёт требует проверки |

## Утверждённые решения

1. Компенсация показывается отдельной отрицательной статьёй расходов, а не скрыто уменьшает другую категорию.
2. Возврат сторнирует себестоимость исходной продажи; при отсутствии связи себестоимость и зависимый результат не рассчитываются полностью.
3. Денежный показатель называется «Маржа, ₽»; «Маржинальность» используется только для процента.
4. Полнота — составной статус, а не условный процент заполнения.
5. Количество знаков после запятой настраивается пользователем; настройка отображения не меняет расчётную точность.

После одобрения паспортов эти решения становятся основанием для [концептуальной модели данных](conceptual-data-model.md).
