# Визуальная система прототипа Grafio

Статус: утверждённое направление кликабельного прототипа. Основано на визуальном аудите существующего frontend Grafio и требованиях недельного финансового сценария.

## Цель

Прототип должен выглядеть продолжением существующего Grafio и одновременно показывать новую логику недельного отчёта. Мы переиспользуем визуальный язык продукта, а состав экранов и порядок данных выводим из требований первой версии.

## Что формирует узнаваемость Grafio

| Элемент | Найденный паттерн | Решение для прототипа |
|---|---|---|
| Рабочее поле | Почти чёрный canvas с точечной сеткой | Точечная сетка покрывает весь экран и не обрезается границами рабочей области |
| Сайдбар | Плавающая стеклянная панель, белое активное состояние, сворачивание до иконок | Раскрытая панель сохраняет подписи; свёрнутый rail имеет ширину 46 px, равную высоте тулбара, и тот же радиус 13 px. Внутри используются строки 32 px, иконки 18 px, логотип 24 px и аватар 28 px |
| Тулбар | Горизонтальная плавающая панель с группами действий и разделителями | Состав адаптируется к доступной ширине самой панели: при раскрытии сайдбара вторичные подписи скрываются, а основные действия остаются доступны. Заголовок отделён от выбора режима сепаратором 1 × 20 px |
| Виджеты | Тёмные карточки с радиусом 12 px, верхним внутренним бликом и строгой типографикой | Переиспользовать для KPI, графика, таблицы и проверки правила. При наведении KPI получает оранжевую внутреннюю подсветку вдоль скруглённого верхнего края и поднимается на 2 px |
| Типографика | Geist Sans для интерфейса, Geist Mono для чисел и технических значений | Сохранить обе гарнитуры и табличное выравнивание чисел |
| Иконки | Тонкие линейные иконки | Сохранить спокойный монохромный стиль |
| Обратная связь | Зелёный, красный и жёлтый используются только для состояния | Сохранить семантику; цветные категории оставить внутри финансовой диаграммы |
| Нижняя панель | Плавающий список листов и отдельный контрол масштаба | Список листов используется для навигации; масштаб доступен только в режиме редактирования свободного canvas |

## Базовые токены

| Роль | Значение |
|---|---|
| Canvas | `#0a0a0a` |
| Карточка | `#1a1a1a`–`#202020` |
| Плавающая панель | `rgba(20, 20, 20, 0.86)` с размытием фона |
| Основной текст | `#fafafa` |
| Вторичный текст | `#a1a1aa` |
| Приглушённый текст | `#6c6c74` |
| Тонкая граница | `rgba(255, 255, 255, 0.07)` |
| Успех | `#22c55e` |
| Ошибка | `#ef4444` |
| Предупреждение | `#eab308` |

Категории структуры расходов используют отдельную палитру, потому что цвет кодирует состав 100%: маржа, себестоимость, комиссия, логистика, маркетинг, эквайринг и прочие статьи.

## Что переиспользуем напрямую

- расположение и пропорции сайдбара;
- логотип из точек и подпись GRAFIO;
- плавающий верхний тулбар;
- canvas с точечной сеткой;
- внешний вид карточек, кнопок, подсказок и переключателей;
- формат KPI: название, единица, крупное значение и изменение;
- паттерн боковой панели для детализации;
- визуальный язык нижней панели; управление масштабом используется только в редакторе пользовательского дашборда;
- состояния пустых, неполных и ошибочных данных.

## Что адаптируем

| Старый элемент | Адаптация |
|---|---|
| Фильтр произвольного периода | Выбор завершённой недели ПН–ВС |
| Фильтр маркетплейса | Юридическое лицо и конкретный кабинет WB |
| Переключатель дневной/недельной группировки | Переключатель рублей и процентов |
| Настройка canvas | Сравнение версий отчёта и переход к методике |
| Универсальная карточка графика | Накопительная структура выкупов по неделям |
| Настройки виджета | Детализация статьи до товаров и операций |
| Студия виджетов | Административная очередь проблем и конструктор правила |

## Что создаём специально для нового сценария

- строку состояния источников, сверки и версии правил;
- накопительную диаграмму «маржа + себестоимость + расходы = 100%»;
- демонстрационные состояния ненулевой сверки, неизвестной операции и новой версии;
- сравнение исходной и исправленной версий отчёта;
- очередь проблем качества;
- карточку расследования с доказательствами и проектом правила;
- контроль «до / после» с обязательным расхождением 0;
- выбор исторического пересчёта или применения правила вперёд;
- предварительный просмотр уведомления пользователям.

## Режимы работы

| Режим | Назначение | Поведение canvas |
|---|---|---|
| Обзор недели | Готовый отчёт для регулярного анализа | Фиксированная структура, обычная прокрутка, без управления масштабом |
| Мой дашборд | Пользовательская компоновка показателей | Отдельный свободный canvas, листы, изменение размеров, масштаб и сохранение раскладки в прототипе |
| Презентация | Демонстрация сохранённого отчёта на созвоне | Раскладка заблокирована, редакторские элементы скрыты |

Прототип позволяет переключать все три режима. «Мой дашборд» вынесен в отдельный пункт сайдбара, поэтому не дублируется в меню режима недельного отчёта. В нём доступны листы, масштаб 50–200%, показ всей раскладки, перемещение canvas, направляющие и история действий. В «Презентации» скрываются сайдбар, тулбар и редакторские элементы. Точечная сетка остаётся одним общим фоном продукта и покрывает весь экран.

## Структура прототипа

```text
Сайдбар + тулбар
├── Недельный отчёт
│   ├── состояние данных и сверки
│   ├── KPI недели
│   ├── структура выкупов по неделям
│   └── детализация статьи и сравнение версий
├── Мой дашборд
│   ├── свободный canvas и четыре проверенных KPI
│   ├── режимы просмотра, настройки и презентации
│   ├── масштаб, миникарта, сетка и линейка
│   └── листы, история действий и направляющие
└── Контроль расчётов
    ├── очередь проблем
    ├── доказательства
    ├── проект правила
    ├── контроль до/после
    └── применение и уведомление
```

В прототипе «Мой дашборд» использует отдельный свободный canvas. Начальный лист содержит только четыре согласованных виджета: выручку, выкупы, маржу и расходы. В режиме «Настроить» доступны перетаскивание, изменение размера за любой угол, привязка к другим карточкам, отмена и повтор действий, сброс и удаление. KPI добавляются и редактируются в отдельной панели выбора метрики. Миникарта охватывает объекты и текущую видимую область, поддерживает переход нажатием и перетаскивание рамки. Панель листов повторяет структуру оригинального Grafio: пустое состояние «С чего начать?», счётчик объектов, переименование, быстрые действия, создание, дублирование, удаление, список всех листов, горизонтальная прокрутка и сворачивание. Состояние хранится только до перезагрузки страницы; это сознательная граница визуального прототипа.
