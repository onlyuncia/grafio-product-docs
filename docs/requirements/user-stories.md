# Пользовательские истории Grafio

Истории показывают, какой результат нужен каждой роли. Правила раскрыты в [бизнес-правилах](business-rules.md), поведение системы — в [функциональных требованиях](functional-requirements.md), проверяемые условия и сквозные примеры — в [критериях приёмки](acceptance-criteria.md).

## Формат и приоритет

`Как <роль>, я хочу <действие>, чтобы <ценность>.`

| Приоритет | Значение |
|---|---|
| Must | Без этого недоступен обязательный финансовый сценарий. |
| Should | Значимо усиливает управленческое использование первой версии. |
| Could | Полезное развитие после закрытия обязательного контура. |

| US-03 | Как финансист, я хочу видеть полноту источников, сверку и версию методики рядом с результатом, чтобы не принять ограниченный показатель за окончательный. | Must | PFR-02—PFR-03, PFR-09, AC-07—AC-09, AT-02, AT-03 |
| US-04 | Как аналитик, я хочу раскрыть статью до доступных товаров и операций, чтобы объяснить изменение суммы. | Must | PFR-07, AC-10—AC-11 |
| US-05 | Как аналитик, я хочу сравнить неделю с историей и увидеть границы методик, чтобы не сделать вывод из несопоставимых периодов. | Should | PFR-08, AC-12, AT-05 |
