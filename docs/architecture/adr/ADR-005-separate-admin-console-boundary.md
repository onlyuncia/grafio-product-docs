# ADR-005. Отдельная граница Admin Console

| Атрибут | Значение |
|---|---|
| Статус | Принято |
| Решение | Admin Console отделена от клиентского рабочего пространства в интерфейсе, правах и API-операциях. |

## Контекст

Клиент может сообщить о расхождении, но не должен менять системную методику. Публикация правила влияет на финансовую историю нескольких периодов и требует независимого контроля.

## Альтернативы

1. Разместить административные действия в клиентском интерфейсе — дешевле в реализации, но смешивает роли и повышает риск ошибочного доступа.
2. Использовать тот же интерфейс с условным скрытием пунктов — визуальное различие есть, но граница безопасности остаётся неявной.
3. Создать отдельный интерфейс и permission boundary Admin Console.

## Решение

Выбрана третья альтернатива. Клиентский кейс передаёт контекст в расследование, но управление черновиком, контроль и публикация доступны только администратору Grafio с MFA. API дополнительно проверяет роль, область и действие — интерфейс не является единственной защитой.

## Последствия

- Клиентская роль не может получить административное действие через прямой URL или вызов API.
- Нужны раздельные маршруты, роли и аудит публикации.
- У процесса появляется понятная передача результата из внутреннего расследования в клиентский кейс.
