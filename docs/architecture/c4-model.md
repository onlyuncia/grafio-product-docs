# C4-модель Grafio

Четыре схемы показывают одну систему с разной степенью детализации. C1 фиксирует пользователей и внешние системы; C2 — приложения, API, фоновый обработчик и хранилища. Две схемы C3 раскрывают **один и тот же сервер приложений**: первая — отчётность, контроль расчётов и методику, вторая — доступ и рабочее пространство.

Это проектная модель [единой архитектуры Grafio](README.md), а не свидетельство внедрения каждого компонента. Синхронизация с WB и Ozon относится к разработанному сервису; воспроизводимый финансовый расчёт, версии отчётов и методика подробно спроектированы для WB. На C2 оба внешних API сгруппированы ради читаемости, на C1 они показаны отдельно. Статус решений указан в [обзоре архитектуры](README.md#модули-и-статус).

Уровень C4 (структура кода) здесь не показан: он имел бы смысл для конкретной реализации серверных модулей, тогда как схемы выше описывают проектные границы.
