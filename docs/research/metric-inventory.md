# Реестр показателей книги WB

Источник: предоставленная рабочая книга WB с обезличенным названием. Это инвентаризация существующих показателей, а не согласованный набор метрик Grafio. Клиентские суммы и товарные записи не перенесены.

Единица учёта — показатель в конкретном представлении. Повторение по неделям, месяцам и товарам не создаёт новых метрик. Одинаковое название с другой формулой сохраняется отдельно. Одинаковые схемы двух товарных сводных объединены с указанием обоих мест использования.

**Статусы:** Ф — найдена формула; З — значение записано без формулы (ручной ввод, импорт или копирование не различимы по файлу); П — только название, расчёт/значения отсутствуют; С — показатель определён в сводной таблице; Ф+З — способ получения различается между периодами. Ошибки и неоднозначности указаны отдельно. Ф и С не означают «расчёт проверен и принят».

Формулы и сохранённые ошибки проверены по всем представленным периодам небольших листов; в строке реестра показан один адрес-пример. Для крупных листов использованы определения формул и сводных. Полный пересчёт Excel и проверка всех зависимостей ошибок не выполнялись. Метод проверки и сверки — в [разборе книги](workbook-calculation-review.md).

Проверено наличие записи для каждой строки показателя недельного и месячного листов и каждого поля значений сводных. Покрытие перечня не означает проверки всех расчётных ветвей. Отдельно остаются смысл единицы строки, атрибуция рекламы, границы периодов, число >1, правила знаков, отсутствующие входы и исправление найденных ошибок.

Локальные ошибки отмечены в строках реестра. Показатель без такой отметки может зависеть от ошибочного или неполного источника. Перед включением в MVP нужны паспорт и контрольные примеры; решения о составе первой версии здесь не принимаются.
