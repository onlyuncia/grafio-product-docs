# Словарь Grafio

Словарь фиксирует значения терминов внутри проекта. Он помогает читать документы одинаково и не заменяет официальные определения Wildberries.

| Термин | Значение в Grafio |
|---|---|
| **Юридическое лицо** | Организация или ИП клиента, которой принадлежат настройки налога, пользователи и один или несколько кабинетов |
| **Кабинет** | Отдельное подключение продавца к маркетплейсу; единица загрузки, доступа и тарификации |
| **Отчётная неделя** | Завершённый период с понедельника по воскресенье |
| **Срез по начислению** | Отнесение операции к периоду по дате финансового начисления WB |
| **Выручка** | Сумма операций продажи по принятому правилу финансового отчёта |
| **Возвраты** | Сумма возвратов, отражённых в текущей отчётной неделе |
| **Выкупы** | Денежная база отчёта: выручка минус возвраты |
| **Расходная статья** | Категория удержаний или затрат, например комиссия, логистика, хранение или штраф |
| **Себестоимость** | Стоимость проданных товаров по настройкам клиента и правилам периода |
| **Маржа** | Денежный результат в рублях: выкупы минус себестоимость и расходы |
| **Маржинальность** | Доля маржи в выкупах, выраженная в процентах |
| **ДРР** | Доля рекламных расходов в выбранной денежной базе |
| **Пользовательский расход** | Расход, который клиент добавляет сам и который отсутствует в источниках маркетплейса |
| **Исходный ответ, raw** | Неизменённый ответ внешнего источника, сохранённый до преобразования |
| **Нормализация** | Преобразование известных полей источника в типизированные сущности Grafio без назначения бизнес-категории |
| **Классификация** | Назначение операции категории по опубликованной версии правил |
| **Неизвестная операция** | Операция, для которой действующая версия правил не определяет категорию |
| **Сверка** | Сравнение рассчитанного значения с контрольным итогом источника |
| **Расхождение, Δ** | Рассчитанная сумма минус контрольная сумма; успешная сверка требует точного значения 0 |
| **Полнота источника** | Подтверждение, что получены все ожидаемые страницы и части данных за период |
| **Версия правила** | Неизменяемый опубликованный набор условий классификации с областью и периодом действия |
| **Область правила** | Маркетплейс, тип данных и при необходимости явно указанный кабинет, к которым применяется правило |
| **Версия отчёта** | Неизменяемый результат расчёта, связанный с точными входами, настройками и версиями правил |
| **Ретроспективный пересчёт** | Создание новых версий отчётов за весь доступный период действия изменившегося правила |
| **Применение вперёд** | Использование нового правила только с указанной даты, когда пересчёт истории невозможен или нецелесообразен |
| **Проблема качества** | Зарегистрированный случай неполноты, расхождения, неизвестной операции или иной причины, мешающей доверять части результата |
| **Идемпотентность** | Свойство повторного запуска не создавать дубли операций или одинаковых версий результата |
| **Пагинация** | Получение большого ответа WB последовательными страницами до подтверждённого окончания |
| **Фоновое задание** | Длительная загрузка, проверка или пересчёт, который выполняется отдельно от открытия экрана пользователем |
| **p95** | Время, быстрее которого завершились не менее 95% измеренных операций |
| **RPO** | Максимально допустимый интервал данных, который может быть потерян при восстановлении |
| **RTO** | Максимально допустимое время восстановления функции после сбоя |
| **AS-IS** | Процесс в исходном состоянии до Grafio |
| **TO-BE** | Спроектированный целевой процесс |
| **NFR** | Нефункциональное требование к скорости, доступности, безопасности или другому качеству системы |
