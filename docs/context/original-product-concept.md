# Product Concept

## What is Grafio
Concierge analytics service for Russian marketplace sellers (WB, Ozon).
Key value: ready-to-use analytics, no configuration needed.

## Target Audience
- Primary: sellers with 1-15M RUB/month revenue
- Users: owners, sales managers, financial analysts
- Pain: fragmented data, manual Excel work

## Business Model
- Subscription (monthly/yearly)
- Trial: 5 days with onboarding
- Tiers by: accounts count, users, features

## Core Features
1. Auto data sync from WB/Ozon
2. Pre-configured metrics and formulas
3. Ready-to-use dashboard
4. Cross-platform view (all marketplaces in one place)

## Competitive Advantage
vs Universal BI (DataLens, PowerBI): no setup, no BI analyst needed
vs Excel: automation, real-time, team collaboration
vs Other tools: cross-platform, flexible pricing
