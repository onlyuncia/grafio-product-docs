# Кликабельный прототип Grafio

Откройте [прототип](https://onlyuncia.github.io/grafio-product-docs/) прямо в браузере. 
В прототипе можно пройти недельный отчёт, РНП, товары, личный дашборд, студию виджетов, контроль расчётов, планы, аккаунт и отдельную Admin Console.

Интерфейс использует синтетические данные. Он демонстрирует сценарии и состояния, но не обращается к целевому расчётному API. 
«Мой дашборд» открывается с пустым листом; виджеты добавляются пользователем. 
[Снимки основных разделов](../screenshots/README.md) доступны для просмотра без запуска прототипа.
