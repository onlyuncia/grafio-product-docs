# Кликабельный прототип Grafio

Откройте [index.html](index.html) локально в браузере. Сервер и установка зависимостей не требуются. В прототипе можно пройти недельный отчёт, РНП, товары, личный дашборд, студию виджетов, контроль расчётов, планы, аккаунт и отдельную Admin Console.

Интерфейс использует синтетические данные. Он демонстрирует сценарии и состояния, но не обращается к целевому расчётному API. [Снимки основных разделов](../screenshots/README.md) доступны для просмотра без запуска прототипа.

Если установлен Node.js, автономные проверки логики можно запустить из корня репозитория командой:

```bash
node --test prototype/dashboard-engine.test.js prototype/weekly-analytics.test.js
```
