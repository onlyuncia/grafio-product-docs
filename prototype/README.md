# Кликабельный прототип Grafio

Откройте [прототип на GitHub Pages](https://onlyuncia.github.io/grafio-product-docs/) или [index.html](index.html) локально в браузере. Для локального просмотра сервер и установка зависимостей не требуются. В прототипе можно пройти недельный отчёт, РНП, товары, личный дашборд, студию виджетов, контроль расчётов, планы, аккаунт и отдельную Admin Console.

Интерфейс использует синтетические данные. Он демонстрирует сценарии и состояния, но не обращается к целевому расчётному API. «Мой дашборд» открывается с пустым листом; виджеты добавляются пользователем. [Снимки основных разделов](../screenshots/README.md) доступны для просмотра без запуска прототипа.

На телефоне в вертикальном режиме навигация открывается кнопкой меню, а инструменты переносятся на несколько строк. Широкие графики, таблицы и ряды карточек Студии прокручиваются внутри своих блоков. Для таблицы товаров доступна подсказка о повороте телефона; её можно закрыть и продолжить просмотр вертикально. В этом режиме таблица прокручивается целиком, без закреплённых столбцов; настройки закрепления сохраняются для широкого экрана.

[Анимированная схема пути финансовых данных WB](flow/index.html) показывает путь от источника до версии недельного отчёта.
