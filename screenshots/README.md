# Экраны демонстрационного прототипа Grafio

Галерея дополняет [портфельный кейс](../CASE-STUDY.md). На скриншотах показан интерфейс с демонстрационными данными; изображения иллюстрируют пользовательские сценарии и не подтверждают работу целевого расчётного API или внедрение у клиентов.
