# Анимация пути данных Grafio

[`grafio-data-flow.webp`](grafio-data-flow.webp) — предоставленная автором анимация для README: 1200 × 314 пикселей, 150 кадров, цикл 4,95 секунды. Исходный WebP сохранён без перекодирования.

Нажатие на анимацию открывает [интерактивную схему](https://onlyuncia.github.io/grafio-product-docs/flow/). Её исходники находятся в [`prototype/flow`](../../prototype/flow/).
